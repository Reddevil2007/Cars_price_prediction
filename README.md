# Cars_price_prediction

## Car Price Prediction using Linear Regression

This repository contains the implementation of linear regression from scratch to predict car prices.

## Dataset
- CarPrice_Assignment.csv

## Approach
- Data preprocessing and one-hot encoding of categorical variables
- Feature normalization using mean normalization
- Linear regression implemented using gradient descent
- Mean Squared Error used as the cost function

## Tools Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Files
- `Car_Price_Prediction_Linear_Regression.ipynb` – main notebook
- `CarPrice_Assignment.csv` – dataset
